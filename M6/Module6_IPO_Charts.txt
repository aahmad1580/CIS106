M6P1 - Widget Total
Input: Quantity of widgets
Processing: If quantity > 10000, unit_price = 10.00;
            otherwise if quantity >= 5000, unit_price = 20.00;
            otherwise unit_price = 30.00.
            extended_price = quantity * unit_price
            tax = extended_price * 0.07
            total = extended_price + tax
Output: Extended price, tax, total

M6P2 - Part Cost
Input: Part number, quantity
Processing: If part number is 10 or 55, unit_cost = 1.00;
            otherwise if part number is 99, unit_cost = 2.00;
            otherwise if part number is 80 or 70, unit_cost = 3.00;
            otherwise unit_cost = 5.00.
            total_cost = quantity * unit_cost
Output: Part number, cost per unit, total cost

M6P3 - CD Interest
Input: Principal amount, years to maturity
Processing: If principal > 100000 and years == 5, interest_rate = 0.06;
            otherwise if 50000 <= principal <= 100000:
                If years == 10, interest_rate = 0.05;
                otherwise if years == 5, interest_rate = 0.04;
                otherwise interest_rate = 0.02.
            For all other principal amounts and years, interest_rate = 0.02.
            first_year_interest = principal * interest_rate
Output: Principal, interest rate, first year interest

M6P4 - Concert Tickets
Input: Number of tickets
Processing: If tickets >= 25, price_per_ticket = 50.00;
            otherwise if tickets >= 10, price_per_ticket = 60.00;
            otherwise if tickets >= 5, price_per_ticket = 70.00;
            otherwise price_per_ticket = 75.00.
            total_cost = tickets * price_per_ticket
Output: Number of tickets, price per ticket, total cost

M6P5 - Employee Bonus
Input: Employee last name, salary, job level
Processing: If job_level >= 10, bonus_rate = 0.25;
            otherwise if job_level >= 5, bonus_rate = 0.20;
            otherwise bonus_rate = 0.10.
            bonus = salary * bonus_rate
Output: Employee last name, bonus
